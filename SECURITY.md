# Security

This folder is an evaluation archive. It does not contain a running service, a model server, or Fusion Aperture.

Please open an issue (when the archive is public) or write to the maintainers if you find an eval error: a hash that no longer matches, a mean that does not recompute, a mislabelled length, or a cousin score that does not match its cited source.

Do not send reports that ask how the stack works, how to attack a local server, or how to extract weights from the product. Those are not in scope here.

The eval host is a third party checkpoint (Qwen3.5-2B, Q4_K_M). Vulnerabilities in that checkpoint belong with its authors.
